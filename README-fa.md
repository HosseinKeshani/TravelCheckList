# ساخت فایل APK (بدون نصب Android Studio)

1. در github.com یک حساب بسازید و یک مخزن (Repository) جدید و خالی بسازید.
2. محتوای این پوشه (همه چیز، از جمله پوشه‌ی `.github`) را در همان مخزن آپلود کنید
   (Add file ← Upload files).
3. به تب **Actions** بروید. ساخت خودکار شروع می‌شود (حدود ۵ تا ۸ دقیقه).
   اگر شروع نشد: Build APK ← Run workflow.
4. وقتی تیک سبز شد، روی اجرا کلیک کنید و پایین صفحه در بخش **Artifacts** فایل
   `travel-checklist-apk` را دانلود کنید. داخل zip فایل `app-debug.apk` است.
5. فایل را به گوشی بفرستید و نصب کنید (اگر اندروید پرسید، اجازه‌ی نصب از منبع ناشناس را بدهید).

## تغییر در اپ
فایل `www/index.html` خود اپ است. بعد از هر تغییر و آپلود دوباره، APK جدید ساخته می‌شود.
نام اپ و شناسه در `capacitor.config.json` است.
